# Repozytorium GitHub — Capri CompanyBot 0.1.1

## Co znajduje się w repozytorium

Główny katalog zawiera tylko README, dokumentację, licencje i listę zależności. Folder `src/` zawiera pliki Pythona i zasoby aplikacji (`src/assets/`, `src/lore/`, `src/Capri.ico`), a `.github/ISSUE_TEMPLATE/` formularze zgłoszeń.

**Repozytorium jest source-only:** nie ma w nim instalatora, EXE, plików `.spec` ani skryptów budowania Windows. Przesyłaj zawartość archiwum do katalogu głównego repozytorium, nie samo archiwum.

## Publikacja przez stronę GitHuba

W istniejącym repozytorium: **Code → Add file → Upload files**. Przeciągnij zawartość rozpakowanych paczek GitHub WEB kolejno, zachowując strukturę katalogów. Każdy zestaw ma mniej niż 100 plików. Zatwierdź każdą część osobno (**Commit changes**). Nie przesyłaj plików `.env`, prywatnych profili ani kluczy API.

## Zgłoszenia i dokumentacja

Formularze zgłoszeń znajdują się w `.github/ISSUE_TEMPLATE/`. Repozytorium nie zawiera skryptów kompilacji Windows, PyInstallera ani instalatora.

## Releases

Gotowy `Capri_Setup.exe`, jeśli zostanie osobno zbudowany i przetestowany, można udostępniać przez **Releases** jako osobny plik, a nie przez repozytorium źródłowe. Wersja tej publikacji to **0.1.1 — Wczesny dostęp**, docelowy tag `v0.1.1`.
