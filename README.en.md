# Capri CompanyBot

**Version 0.1.1 · Early Access · Windows**

A Polish-first desktop AI voice companion with a cyberpunk-inspired interface, conversational memory, optional local language models, speech recognition, speech synthesis, and selected computer-control features.

> **Independent fan project.** Capri CompanyBot is not developed, approved, endorsed, sponsored, or affiliated with **CD PROJEKT RED**. Cyberpunk-related names, characters and trademarks belong to their respective owners.

## Features

- Conversational AI through Ollama, including configurable Qwen and Bielik models, with optional online APIs.
- Multi-turn conversation context, character personality, emotions, and local memory.
- Whisper / Parakeet speech recognition and configurable text-to-speech engines, including optional Fish S2.cpp.
- Desktop themes (Basic, Holocall, Silverhand), avatar and Mini mode.
- Optional PC agent controls, media playback and Spotify integration.

Some features require separate models, backends, accounts or hardware. This is an early-access project and not every feature is guaranteed to work on every system.

## Getting Capri

Check [Releases](https://github.com/Suver112/Capri-CompanyBot/releases) for **published** installers, when available. A source repository is not a prebuilt Windows distribution.

To run source code locally, see the [Polish README](README.md). The application requires separate setup of any desired local LLMs and optional speech components.
